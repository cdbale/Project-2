# Project 2: Mile High Stays

Following its acquisition, Mile High Stays wants to update its Denver pricing
model and strategy. Develop a model of advertised nightly prices, use it to
recommend initial prices for client-provided properties, and assess whether
relationships observed in Seattle and Portland strengthen or qualify your
recommendations for Denver.

## Materials

- **Project 2 Instructions.pdf**: business context, client requests, data dictionary,
  and deliverables.
- **Rubric V2.pdf**: assessment criteria and the 100-point scoring system.
- **mile_high_stays.csv**: 6,522 market listings across Denver, Seattle, and Portland.
- **client_properties.csv**: 20 Denver client properties requiring pricing
  recommendations; prices are omitted.
- **Project-2.Rproj**: open in RStudio to work from this folder.
- **SOURCES.md**: data attribution and preparation notes.

Both data files use commas and can be imported with `read_csv()`.

Submit a rendered analysis document and a one-page executive summary, as
described in the instructions. Include the client-property pricing table in
the analysis document.
